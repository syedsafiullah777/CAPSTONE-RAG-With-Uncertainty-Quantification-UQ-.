## Synthesis

| Observation | Evidence |
| --- | --- |
| Retrieval quality improved | Cases 1, 5 |
| Warnings reduced overconfident responses | Cases 1, 4, 6 |
| Abstention reduced unsafe answers | Cases 2, 3, 7 |
| Confidence estimation still has limitations | Case 8 |

## Takeaway

The qualitative evidence supports the quantitative results: the proposed UQ system can improve safety by abstaining or warning when evidence is weak, but the confidence score is still only a weak predictor of answer quality. In several cases it correctly mirrors uncertainty; in at least one case it remains confidently wrong. Although the uncertainty mechanism improved cautious behaviour in several examples, Case 8 illustrates that moderate confidence does not guarantee correctness. This limitation is consistent with the weak correlation observed in the calibration analysis and highlights an opportunity for future refinement.
